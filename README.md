# File Organizer Automation (Python)

This project automatically organizes files into folders based on file type and renames files in bulk.

## Features
- Sorts files into folders (Images, Documents, Videos, Others)
- Renames files in bulk
- Helps automate file management

## Tech Used
- Python 3
- OS module
- Shutil module
